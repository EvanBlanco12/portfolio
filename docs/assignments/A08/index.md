# A8 – [Gears]

## Objective
For this assignment, we were tasked with designing a gearbox using two spur gears, consisting of a pinion and a larger gear. The given gear ratio is 24:9, with an output torque of 1.25 in-lbf and an output speed of 1100 rpm. The input shaft has a diameter of 0.125 inches, while the output shaft has a diameter of 0.25 inches. Both shafts have a length of 1 inch. The main goal of this assignment is to design a functional gearbox by analyzing the shafts, selecting appropriate journal bearings, and creating a two-piece housing that can be assembled and disassembled.

Lessons Learned

1. Creating the mounting holes was more difficult than I expected.
When I first started making the holes for the gearbox housing, I thought it would be a quick process. However, I realized there were several different hole options and settings that I wasn't familiar with. Figuring out the correct hole sizes and making sure everything lined up between the two halves took more time than expected. Looking back, I would spend more time planning the hole locations before adding them to the model.

2. Assembling the gearbox was easier than I originally thought.
Going into this assignment, I expected putting all the components together to be one of the harder parts. Once I started using the mating features in SolidWorks, I found that positioning the gears, shafts, and housing components was pretty straightforward. This helped me better understand how different parts are constrained in an assembly.

3. Understanding the calculations took some extra time.
One thing I learned was how many different calculations go into designing a gearbox. At first, it was confusing trying to figure out which equations to use and how the different values related to each other. After working through the shaft stresses and bearing calculations, I had a better understanding of how these calculations affect the overall design.

4. Downloading existing CAD components saved a lot of time.
Before this assignment, I didn't realize how useful it was to download existing parts directly into a CAD assembly. Being able to use premade models for components like gears and bearings made the modeling process much easier. Instead of spending time creating every individual part, I could focus more on designing the actual housing and making sure everything fit together correctly.

5. Planning ahead would have made the design process smoother.
Another thing I learned was the importance of having the dimensions and component locations figured out before starting the CAD model. Making changes later in the process can affect other features and create additional work. If I were to complete this assignment again, I would spend more time preparing my initial sketches and checking measurements before modeling.

Time Spent

The total time I spent working on this assignment was approximately 5 hours. A good portion of that time went toward understanding the calculations and figuring out how to properly design the gearbox housing. I also spent time adjusting the CAD model, working with the assembly features, and making sure the different components fit together correctly. Overall, this assignment helped me become more comfortable with gearbox design and understand how calculations are applied to an actual mechanical assembly.
