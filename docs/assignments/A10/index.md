# A10 – Lead Screw Translating System
Evan Blanco, Jake Umebayashi, Grady Stallings

## Objective (Evan)
The assignment this week is to design a mechanically driven tensile tester that can apply up to 2 kN of pulling force to a test specimen. The machine will use a lead screw system to control the movement of the crosshead and must provide rotational speeds between 1-50 mm/min.
The key focus of this project is the design of the lead screw and the dimensions of the crosshead both calculated from the forces seen within the tensile tester.
